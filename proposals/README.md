# Proposals

Each change to the core of Rowih, and each release of a dialect, is proposed in a file of this directory, named by its number and a few words, as `0001-a-root-for-forecasting.md`, and added by the pull request that makes the change. A merged proposal stays here as the record of its change. The format is stated in [the format of a proposal](../governance/proposals.md), a new proposal starts from [`TEMPLATE.md`](TEMPLATE.md), and [How Rowih changes](../governance/README.md) states the rule of change and the gate a proposal must meet.
